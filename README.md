# Planifica para Windows

Descarga oficial de Planifica, la aplicación de planificación semanal para
docentes de Informática y Tecnología.

## Descargar

[![Descargar Planifica para Windows](https://img.shields.io/badge/Descargar-Planifica%20para%20Windows-2563eb?style=for-the-badge&logo=windows&logoColor=white)](https://github.com/JorgeMeraz107/planifica-downloads/releases/latest/download/Planifica-Setup.exe)

El enlace siempre descarga la última versión publicada.

- Windows 10/11 de 64 bits.
- Instalación por usuario, sin permisos de administrador.
- Crea accesos directos en el Escritorio y en el Menú Inicio.
- Los datos se guardan localmente y se conservan al desinstalar.

El instalador no está firmado digitalmente, por lo que Windows SmartScreen puede
pedir confirmación la primera vez. Descarga únicamente desde este repositorio
oficial y, si aparece la advertencia, revisa el nombre del editor antes de
continuar.

Al instalar o usar Planifica aceptas la licencia de uso personal o educativo
incluida con el software.
